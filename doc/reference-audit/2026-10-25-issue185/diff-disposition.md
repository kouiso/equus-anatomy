# 差分の対応付け(実装済み/既存PBI/新規PBI/対象外/未解決)

台帳・coverage-matrix・feature-diff の各差分を5分類へ写像した結果。
新規PBI番号は起票後に追記する(下表の「新規PBI」列)。

## 構造収録の差分

| 差分(系統単位) | 判定 | 対象 |
|---|---|---|
| 体表ランドマーク | **実装済み** | Equus 30項で網羅先行。微細ランドマーク(蹄球・踵等)は個別PBI不要の水準 |
| 骨格の部位群レベル(椎骨群・肋・指節骨等) | **実装済み** | Equus 26項は主要骨を収録済み |
| 骨格の個別骨レベル(C1-C7・T1-T18・L1-L6・R1-R18・手根骨各骨・跗骨各骨) | **新規PBI** | 新規「骨格の個別化」 |
| 筋の浅層・中層 | **実装済み** | Equus 21項 |
| 筋の深部(棘上/棘下/腸腰筋/鎖骨下筋の座標なし + 深部筋) | **既存PBI** | #50(深部筋画像, blocked-external)・#164(次バッチ設計) |
| 腱・靭帯・関節・蹄内部 | **既存PBI** | #5(blocked-external)。注釈画像 public-images/pbi-tendon-ligament.png で位置特定を補完 |
| 内臓図版の品質 | **既存PBI** | #4(blocked-external) |
| 右面専用図版(内臓の左右非対称) | **既存PBI** | #49 |
| 獣医監修 | **既存PBI** | #13 |
| 神経系統(中枢+末梢) | **新規PBI** | 新規「神経系統の収録」 |
| 血管系統(動脈+静脈) | **新規PBI** | 新規「血管系統の収録」 |
| リンパ系統 | **新規PBI** | 新規「リンパ系統の収録」 |
| 呼吸器内部(気管・喉頭・副鼻腔・横隔膜・鼓胞) | **新規PBI** | 新規「呼吸・消化器の内部構造拡充」 |
| 消化器内部(食道・十二指腸・直腸・膵臓・唾液腺) | **新規PBI** | 同上(呼吸・消化器を1PBIに併合) |
| 泌尿生殖器(雌雄別) | **新規PBI** | 新規「泌尿生殖器(雌雄)の収録」 |
| 歯(切歯・犬歯・臼歯・乳歯/永久歯) | **新規PBI** | 新規「歯の部位別収録」 |
| 感覚器・内分泌(眼球内部・耳・甲状腺・副腎・下垂体) | **新規PBI** | 新規「感覚器・内分泌腺の収録」 |
| 断面・編集用オブジェクト(planos等) | **対象外** | 編集用UIであって構造収録ではない |
| クイズ機能 | **対象外** | AGENTS.md で明示的除外 |

## 機能差分

| 機能差分 | 判定 | 対象 |
|---|---|---|
| 層切替・部位選択・保存 | **実装済み** | 現行維持 |
| 右面図版 | **既存PBI** | #49 |
| 部位の解説文・音声発音・クローズアップ | **未解決** | RBW にあり Equus に無い。構造収録PBI群の完了後に個別検討(現状は構造不足で前提が無い) |
| 系統別表示の拡張 | **新規PBI群の受入条件に包含** | 各新規PBIで新層/タグを定義 |
| 左右個別構造の選択 | **未解決** | 左右別データモデルが必要。新規PBI群で左右を収録後に検討 |
| 雌雄差の表示 | **新規PBIの受入条件に包含** | 泌尿生殖PBI |
| RBW 構造単位の対応付け | **未解決** | 構造一覧が未取得のため。Biosphera の構造群を仮の目安とする |
