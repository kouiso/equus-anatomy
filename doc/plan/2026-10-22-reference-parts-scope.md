# 部位・名称の収録方針（2026-10-22）

## 目的

3D Horse Anatomy に収録される骨・筋肉・内臓などの部位・名称を全て洗い出し、全ての位置も正確にして、2Dの Equus Anatomy に漏れなく収録し参照できるようにする。
これは参照アプリの機能模倣や3D制作の計画ではない。
公式desktop一覧692掲載行と現行87項目の対照表を受領し、[監査台帳](../reference-audit/2026-10-22/README.md)へ導入した。692は掲載行数であり、左右や集合骨を展開した総個数ではない。mobile実体との一致・全網羅・位置の正確性は未確認。原台帳の候補を保持し、一覧や存在しない座標を推測で生成しない。

## 対象外と維持するもの

- 想定ユーザーと合わないため、クイズ・出題・採点・誤答再学習を新規実装・復活しない。自己テストをクイズの代替として追加する案も対象外。これらを完成条件に含めない。
- 保存、手動の「覚えた」、取り消し、既存記録の読み込み互換を維持する。`equus.saved.v1` / `equus.mastery.v1` の削除・初期化・破壊的な移行は行わない。
- `correct` / `wrong` / `streak` は既存データの互換のために残っている。存在を理由に新しい採点や復習機能を計画しない。今回、型・読込・判定・更新処理は変更しない。
- 既存UIの修正、データ、画像、検証記録を保持する。[Draft PR #209](https://github.com/kouiso/equus-anatomy/pull/209) の部位名可読性修正と前後画像はそのまま残す。
- 医学・獣医学の内容を推測で補完しない。認証回避、無許可取得、ライセンス不明の画像の取り込みを行わない。

## 対照調査の受け取り方と次の仕事

1. 受領した692掲載行の対照表の版・出典・確認範囲を保持し、名称候補を根拠付きで審査する。掲載行・左右展開・集合骨内の個別構造を区別し、未確定の総数を断定しない。
2. 各参照構造をEquusの構造IDへ対応付け、収録済み・不足・対応未確定を区別する。和名・英名・ラテン名の表記差や別名は根拠を確認する。本文中の言及や複数部位の一括名だけで個別収録済みにしない。
3. 名称の収録と、位置・左右・深さ・隣接関係・2D投影の検証を別に記録する。2Dの配置・選択到達性も確認する。図が無くても不足の追跡は続ける。図が無いことを参照アプリに未収録である根拠や、収録対象から除外する理由にしない。
4. 不足に対し、名称・検証済み説明、利用可能な図版と権利、座標測定、検索・一覧・詳細・図への導線のどこが未完了かを分けて実装計画を立てる。未監修・下書きの表示を維持する。
5. 調査で確定した対象ごとに、名称を検索・一覧・詳細で参照できることを検証する。2D配置がある部位は、その図・向き・層で選択できることも確認する。未配置や未確認を完了件数へ混ぜない。

対照表には最低限、参照名・分類、参照版と出典、Equus ID、名称収録状態、位置検証の台帳ID、未完理由を記録する。
総数と対応未確定が残る間は、収録数の増加や既存テストの成功だけで「全て網羅した」と報告しない。

## 位置の正確性を別に追跡する

位置検証台帳は構造・向き・層・深さごとに、次の項目を独立して未確認・確認済み・要修正として記録する。
現在の台帳は692行とも位置未確認。根拠を取得・審査するまで新しい座標は作らない。

| 項目 | 必要な確認と根拠 |
| --- | --- |
| 位置 | 対象構造の位置・範囲が、出典の対象構造と一致するか |
| 左右 | 左右の区別、存在側、左右別構造の対応。単純反転を正しさの根拠にしない |
| 深さ | 表層・深層、他構造による被覆、層の対応 |
| 隣接関係 | 周囲の骨・筋肉・内臓などとの接続・重なり・前後関係 |
| 2D投影 | どの向き・投影で対象が見えるか、隠れる部分、図上の領域への対応 |

各項目に出典・対象版・対応図と画像ハッシュ・確認範囲・確認者またはレビュー記録・未完理由を結び付ける。
`source: draft` の位置や未確認の関係を推測で補完して完成にしない。シルエット内、画像ハッシュ一致、タップ成功、`validate:coords` 合格は幾何学・実装の確認であり、解剖学的な位置の正確性を単独で保証しない。

## 完成条件

- 参照アプリの全構造一覧の対象版・出典・確認範囲が明確で、未確認範囲が解消している。
- 各構造のEquusへの対応が確定し、不足・重複・表記差が追跡できる。未確定の対応を収録済みに数えない。
- 対象の部位・名称を2Dアプリで検索・閲覧して参照でき、全対象の位置・左右・深さ・隣接関係・2D投影が根拠付きで確認済みになっている。名称だけの登録、未配置、下書き、位置未確認を正確な収録完了に数えない。
- 既存保存データを維持し、変更に応じた型・lint・単体・座標・Webの検証を行う。未実施のnative・実機検証は別に記録する。
- クイズ・誤答再学習の実装や成績を、上記の完了条件にしない。
