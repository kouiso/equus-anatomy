| 項目 | 内容 |
|---|---|
| タイトル | 解剖コンテンツを獣医レビュー可能な品質に仕上げ、獣医の確認を通す |
| 価値 | 商用化の第一関門。獣医の NG が出た内容は商用アプリに出せない |
| 現在地 | AI監査で確定誤り7件を修正済み。獣医判断10件と全件台帳を `doc/review/2026-09-18-vet-audit/` に整備済み |
| 完了条件 | ①獣医が確認項目10件に回答した記録がある ②指摘された修正が反映済み ③draft座標の扱い（獣医測定で昇格/修正）が決まっている |

## 依存と順番

```
SBI-3（レビュー会）
  → SBI-4（裁定反映）
    → SBI-7（draft昇格の流れを獣医と詰める）
SBI-5 は商用化判断と独立して進められる（獣医の所感があれば併せて聞く）
SBI-8 はレビュー会の前に済ませると獣医が実機で触れる（推奨順）
```
