# Google Play データセーフティ — 回答ドラフト

提出時（#55）に Play Console の「アプリのコンテンツ → データセーフティ」へ転記する下書き。
最終回答は人が Console 上の質問文を確認してから行う。

## 根拠

- アプリは通信機能を持たない。サーバー・API・アカウント登録は無い
- 解析・広告・クラッシュ報告・課金の SDK は入っていない（`package.json` の dependencies は Expo / React Native の UI・フォント・ルーティング・AsyncStorage のみ）
- 端末内に保存するのは「覚えた」印と保存（ブックマーク）だけで、AsyncStorage に置く。外部へは送らない
- Android の OS バックアップは無効（`app.json` の `android.allowBackup: false`）
- 権限は `INTERNET` 以外を `blockedPermissions` で剥奪済み（`INTERNET` は React Native / Expo の既定で残る。アプリのコードからの通信は無い）
- プライバシーポリシー: `doc/privacy-policy.md`（公開 URL は #45 の解消後に `https://equus-anatomy-84f.pages.dev/privacy-policy.html`）

Play のデータセーフティでは「端末内でのみ処理され、デベロッパーや第三者へ送信されないデータ」は「収集」に当たらない。
「覚えた」印と保存はこれに該当するので、申告対象のデータは無い。

## 回答

| 質問 | 回答 |
|---|---|
| 必須のユーザーデータの種類のいずれかを収集または共有していますか？ | **いいえ** |

「いいえ」と答えると、以降の「データの種類」「暗号化」「削除リクエスト」の質問は出ない。

| データの種類 | 収集 | 共有 | 備考 |
|---|---|---|---|
| 位置情報 | なし | なし | |
| 個人情報（氏名・メール・ID 等） | なし | なし | アカウント無し |
| 金融情報 | なし | なし | 課金無し |
| 健康とフィットネス | なし | なし | |
| メッセージ | なし | なし | |
| 写真と動画 / 音声 | なし | なし | |
| ファイルとドキュメント | なし | なし | |
| カレンダー / 連絡先 | なし | なし | |
| アプリのアクティビティ | なし | なし | 「覚えた」「保存」は端末内のみ |

## 回答を変える必要が出る変更

次のどれかを入れたら、このドラフトとプライバシーポリシーを先に直してから提出する。

- クラッシュ報告（Sentry 等）・解析（Firebase Analytics 等）・広告 SDK の追加
- 通信を伴う機能（同期・ログイン・OTA 更新の `expo-updates` 等）の追加
- `allowBackup` を `true` に戻す（Google のバックアップへ送られる）

## 配布経路の補足

Firebase App Distribution（テスター配布）は配布経路の話で、アプリ本体のデータ収集ではない。Play 版の申告には含めない。
