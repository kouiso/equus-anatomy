| # | 不具合 | 重症度 | 対応 |
|---|---|---|---|
| D-1 | `/overlay?kind=...` を直接開くと React #418（hydration mismatch）がコンソールに出る。静的書き出しではクエリが無いので本文が食い違う | 低（描画は回復するが毎回エラー＋再描画） | `overlay.tsx` / `+not-found.tsx` で本文をマウント後描画に変更（web のみゲート）。回帰テスト `e2e/errors.spec.ts` |

| 領域 | 理由 |

| 内臓の絵 | #4 で差し替え予定のもの。現行版で表示は出る |
| Cloudflare Pages への実デプロイ | secrets 未設定。`dist/` は生成済み、404.html も Pages の規約どおり |
| 同時多タブ操作・オフライン | 想定利用が単一タブの静的学習アプリなので対象外と判断 |

## 再現方法

```bash
pnpm install && pnpm build
pnpm exec serve dist -l 4187        # http://<WSL IP>:4187 （この環境は localhost 中継オフ）
pnpm e2e                            # 全79件。webServer が自動で build+serve する
```

手動でやる時の注意: **serve する `dist/` は必ず直前に build し直す**。古い dist に当たると「直したはずが動かん」調査に時間を食う（実際に踏んだ）。
