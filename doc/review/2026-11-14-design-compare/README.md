## 読み方と測り方

- 「デザイン」の値は、`.dc.html` の CSS をそのまま引いた（引用）か、PNG から読んだ。
- 「実装」の値は、証跡画像のピクセルを測った。390px・320px の画像は 2 倍（780×1688・640×1136）、1440px の画像は 2880×1800 なので、**CSS px = 画像の px ÷ 2**。色は画像から直接サンプルした。
- **単位**: 表の「実装」の px は、特に書かない限り **CSS px（画像の px ÷ 2）**。「画像の px」と書いた物（例: 区切り線 610px〜1538px、y=1550px、「115 × 47px」）は 2 倍の画像上の値。
- **1440px の値**: 2880×1800 の画像を 2000px 幅で表示して読んだ物は、表示の座標 ÷ 1.389（= 2000 ÷ 1440）で CSS px にした。この読みは目視を含むので、「約」を付けた。2880px の画像上で測った物は ÷ 2。
- **320px の画像について**: `doc/evidence/255/after-anatomy-320-2x.png`・`doc/evidence/256/after-catalog-320-2x.png` ほか `*-320-2x.png` は、画面の倍率が 2 倍（DPR 2、640px 幅）の画像で、**文字 200% ではない**。#255（本文 39〜40 行）と #256（本文 37〜38 行）の 320px・文字 200% の行は既に `[x]` で、証跡にこの画像を挙げているが、その `[x]` の根拠は、同じ行に並ぶ e2e（`e2e/anatomy-condition-chips.spec.ts`、`e2e/catalog-compact-list.spec.ts` ほか）であり、この画像ではない。画像の引用は別に直す。
- 測れなかった物、画像から確定できない物は **（未確認）** と書いた。`.dc.html` に無い値は作っていない。
- **デザインの枠は 360px 幅（390px 案と表示）**。`.ph` が幅 360・高さ 760。390px の実装と横幅が違うので、左右の余白は ±2px 程度の差を「一致」と見なした。縦に積む高さ（チップ 44px など）は枠幅に依らないので、そのまま比べた。
- **デザインの 1440px の列は 760×560 に縮小して描いてある**（`.dk`）。そのため、その列のチップ高さ（36px）や右の欄の幅（268px）は実寸ではない。実寸で比べる所は「並び・色・文言」に絞った。
- デザインの青い枠（`.new`）と「案」「今」の札は、レビュー用の注記で、画面の部品ではない。比べていない。
- 色の変数（デザイン CSS）: 背景 `#0b0c0e`（--bg）、面 `#14161a`（--sf）、チップ `#1e2126`（--rs）、罫線 `#262a30`（--ln）、骨色 `#ddcba4`（--bone）、骨色の上の字 `#17140d`（--onb）、補助の字 `#9aa2ac`（--mu）。
