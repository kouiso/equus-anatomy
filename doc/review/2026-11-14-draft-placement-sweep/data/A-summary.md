# Sweep A: gross placement check (origin/develop, left/front/rear)

Method: each part polygon drawn on its layer plate (full overview per view/layer plus per-part crops with plain comparison), judged by eye. Not boundary precision.
Scripts: draw.js, mk.js; images in out/; verdicts in results.json.

Verdict key: yes = on named structure; no = on a clearly different structure; cannot tell = illustration unclear.
Caveats: single reviewer; some verdicts (front sternum, left fetlock) are medium confidence. Ids with no `names` (muscles) were judged by id.

See report in the handback message for counts and the full "no" list.
