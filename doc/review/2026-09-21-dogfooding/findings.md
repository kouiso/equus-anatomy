## 実不具合・UI 崩れ

### F1 [中] 構成変更リロード後、全画面のヘッダーがステータスバーの下に潜り込む

**どこが**: 全画面の上部ヘッダー(解剖/図鑑/保存タブおよび overlay「表示条件」「部位一覧」「部位の解説」)
**何が**: タイトルと時刻・通知アイコンが同じ行に重なり、タイトルが半分欠ける(写真 `shots/annotated-f1-header-overlap.png`)
**再現手順**: アプリ起動中にシステム設定を変えて Activity 再生成+JS リロードを起こす。今回 `adb shell settings put system font_scale 1.3` で一度だけ発生。発生すると app-header の `useSafeAreaInsets().top` が 0 を返すようになり `paddingTop: max(16, insets.top)` が 16 まで縮む。以降は force-stop して再起動するまで直らない
**確実性**: 再現は不安定(同じ font_scale 操作を二度目にやった時はリロード自体が走らず不発)。Expo Go の dev セッション固有の可能性が高いが、release ビルドでも同じ経路(RN の config change → insets 再取得)があり得るので要検証
**影響するユーザーストーリー**: 文字を大きくしている高齢の調教師・学生が、設定を変えた直後にヘッダーが読めなくなる
**推定原因**: `react-native-safe-area-context` の insets が in-place reload 時に古い/ゼロ値を返す。`src/ui/app-header.tsx:17`

### F2 [低] 位置未登録部位でも「図」「解剖図で位置を見る」が出て、飛ぶと真っ黒な空キャンバス

**どこが**: 図鑑一覧の各行の「図」ボタン / 詳細の「解剖図で位置を見る」
**何が**: 棘上筋・棘下筋・鎖骨下筋(馬)・腸腰筋・膀胱など、図上に点が無い部位でもリンクが出る。飛ぶと ①深層筋は plate 自体が無く真っ黒+「この層の図はまだありません」、②膀胱などは図は出るが「この部位は現在の図では位置が未登録です」と選択だけされる(写真 `shots/annotated-f2-map-deadend.png`、`shots/t5-map-jump.png`)
**再現手順**: 図鑑で "spin" と検索 → 棘上筋の「図」をタップ → 真っ黒キャンバスに着地
**影響するユーザーストーリー**: 「場所を確認したい」のに何も見えない。期待と落差がある
**提案**: 一覧・詳細で位置未登録の部位は「図」ボタンを出さないか「図なし」バッジにする。飛んだ先で最近傍の掲載向き/層へフォールバックするのでもよい

### F3 [低] 「表示条件」で現状態が深層筋だと、選択中=無効 の曖昧表示になる

**どこが**: 表示条件モーダルの「深さ」チップ行
**何が**: 深層筋の部位(棘上筋など)から図ジャンプで来ると depth=deep のままモーダルが開く。深層筋チップは「disabled だけど選択中」という曖昧な色(くすんだクリーム)になり「この条件の図はまだ登録されていません」が出る。どれが有効/選択中か一見分からない(写真 `shots/annotated-f3-deep-chip.png`)
**再現手順**: 図鑑→棘上筋→図で見る→解剖で表示条件を開く
**影響するユーザーストーリー**: 深層筋に迷い込んだ学生が「この条件で表示」を押すと空の図に戻るだけ

### F4 [低・dev のみ] Expo Go の歯車(Tools)がアプリのリセット/閉じるボタンに被さる

**どこが**: 解剖画面右上の「全体に戻る」ボタン、および overlay ヘッダーの「閉じる」
**何が**: dev メニューの浮遊歯車がちょうど重なり、タップすると dev メニューが開いてしまう(写真 `shots/annotated-f4-devgear.png`)
**影響**: 開発中の dogfooding がやりにくいだけ。本番ビルドには無関係(dev-only)。記録として残す

## 使いにくさ・詰まりポイント

### U1 [中] 解剖タブの表示状態(向き/層/場所/選択/ズーム)がアプリ再起動で初期化される
- force-stop→再起動で必ず「左側望・筋肉・表層筋・場所未選択」に戻る。保存/覚えたは AsyncStorage 永続化されるのに表示条件だけ揮発。授業で続きから見たい学生には毎回数タップ余分に必要
- 提案: 最後の表示条件だけでも AsyncStorage に残す

### U2 [低] 図鑑の日本語検索は今回エミュレータ上で直接検証不可
- エミュレータに日本語 IME が無く `adb shell input text` は ASCII のみ(日本語送信は NPE)。検索は英名/カナマップの `normalizeQuery` 経路を "liver"/"spin" で確認(単体テストでもかな検索はカバー済み)。実機・日本語 IME での最終確認を推奨

### U3 [低] ピンチズームは adb から検証不可
- `adb shell input` は単一ポインタのみ。+/−/ドラッグ/リセット/ズーム中タップの正確性は全て確認済み。ピンチ自体は web e2e(`gestures.spec.ts`)でカバー済みとのこと

### U4 [低] 空の深層筋へ遷移後に「この条件で表示」を押すと真っ黒キャンバスへ戻る
- F3 と同根。行き止まり感が強い。「この条件の図はまだ登録されていません」状態では適用ボタンを無効化するほうが親切

## 機能提案(足りないもの)

- **P1 [提案]** 深層筋4部位(棘上筋/棘下筋/鎖骨下筋/腸腰筋)は現状どの向きでも図上に存在しない。図鑑行に「図なし」バッジを出す、またはプレースホルダ図を用意すると「探しても見つからない」が防げる
- **P2 [提案]** 保存タブに「覚えた」フィルタ or 学習進捗(覚えた N/52)の表示があると、獣医学生の復習導線になる
- **P3 [提案]** 部位詳細に学名/和名のコピー(長押し等)があるとレポート作成時に便利
- **P4 [提案]** 解剖図のラベルが省略される部位(未配置含む)への導線は部位一覧に限定されている。部位一覧行に位置未登録マークはあるが、未配置部位の「おおよその位置」を影で示すとさらに親切

## テスト上の制約(未検証/部分検証)

- ピンチズーム: adb では二本指ジェスチャーを注入できず未検証
- 日本語直接入力: エミュレータに日本語 IME 無し。ASCII クエリで同じフィルタ経路を確認
- F1 の再現性: 観測は1回。config-change 再生成で発生と推定、release ビルドでの再現確認を推奨
- 「この層の図はまだありません」条件の overlay→適用ボタン無効化はされていない(仕様の範囲内)
