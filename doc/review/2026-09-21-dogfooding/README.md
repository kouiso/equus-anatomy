## 最重要所見(1分要約)

1. **絵が最大のボトルネック** — 解剖プレートはAI生成で解剖学的疑義+権利未確定。内臓の右側望は左図の反転で解剖学的に誤り(肝臓/盲腸が右側なのに未配置、胃/脾臓の絵が右に見える)。筋肉図は繊維テクスチャが均一で筋の境界が視認不能
2. **F1: 構成変更リロード後にヘッダがステータスバーに潜る**(全画面、`insets.top=0` 化)。Expo Go dev で観測。release ビルドで要再現確認
3. **操作が多い**: 部位の解説まで6操作・条件変更は4操作+モーダル。OOUI化(層めくり+その場シート)で半減可能
4. **説明文の臨床フックは33%のみ**(17/52)。怪我/症例/観察点の欠落が初学者・実務家の両ペルソナに効く
5. **未配置6部位**(深層筋4+膀胱+盲腸)は図鑑から飛んでも行き止まり。「図」ボタンの出し分け or 代替着地が要る
