## 新規 Finding

### R3-F1【低】保存タブ行内「図で見る」→解剖→ハードウェアBACK が保存でなく図鑑一覧に着陸
- 手順: 保存タブ → 部位行の「図で見る」→ 解剖 (部位選択される) → ハードウェア BACK
- 観察: 保存タブではなく図鑑一覧 (直前の検索語が残った状態) に着陸。蹄・腎臓で再現
- 非対称: 図鑑詳細経由の「図」では BACK が図鑑に正しく戻る。in-app の「保存へ戻る」ボタンも /saved へ正しく遷移するため、ハードウェア BACK だけが expo-router のタブ履歴に落ちる
- 期待: 入口が保存タブなら BACK も保存タブへ戻る (または図鑑側と対称な挙動に揃える)
- 証跡: `r3-05j` 〜 `r3-05n` (map-direct → back → 図鑑一覧着陸)

### 補足観察 (仕様の可能性、要判断)
- 図鑑の検索クエリは 詳細→戻る でも保持される。入口の文脈維持としては好ましいが、別タブ経由で戻った際に「検索済み一覧」に見える混乱の余地あり
