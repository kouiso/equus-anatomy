# Dogfooding test plan — EQUUS 馬体解剖 (Android emulator)

環境: emulator-5554 (Pixel 6 Pro, 1440x3120), Expo Go 57.0.9, Metro localhost:8081。
駆動: `adb shell input tap/swipe/text` + `screencap` (screencap は 1440x3120 フル解像度で adb 座標と 1:1 確認済み)。
補助: `/tmp/t.sh` (`t X Y` / `s path.png`)。証跡は `shots/NN-desc.png`。JS エラーは `/tmp/logcat_err.log` + `adb logcat -d ReactNativeJS:* *:S`。

UI 座標は各画面のスクリーンショットから実行時に決める (テキスト位置を画像で確認→tap)。

## テストケース

### T1. 解剖: 表示条件マトリクス
1. 「表示条件」を開く → 向き 4 × 層 4 の組み合わせを順に適用。
   - PASS: 各組で図が描画されるか「この層の図はまだありません」等の明示メッセージ。真っ暗/クラッシュは FAIL。
   - 筋肉選択時に「深さ」チップ(表層筋/深層筋)が出る。深層筋が図未登録ならチップ disabled + 「図が未登録の深さは選択できません」が出ること。
   - 「この条件の図はまだ登録されていません」note が非登録条件で出ること。
2. 右側望で「左側望の図を左右反転して表示しています。」が panel に出ること。

### T2. 解剖: 部位選択
1. 初回は「大まかな場所を選んでください」(area mode)。点をタップ → 場所が選ばれ「場所を選び直す」が出る。
2. 部位マーカー/ラベル/ポリゴンをタップ → panel に部位名 + summary + 「詳しく読む」。
3. 背景(馬体外)タップ → 選択なしのまま / 選択解除される。
4. 耳介×頭部の重なり領域: 小さいマーカー側をタップ → 耳介が選ばれる(大ポリゴンに負けない)。
5. 「未配置 N 件」notice が出る条件(内臓 左/右 等)で件数と文言を確認。
6. draft(破線)と測定済み領域の描画差を目視。
7. 「選択を解除」→ 選択が消える。「場所を選び直す」→ area mode に戻る。
8. 「部位一覧」overlay → 部位タップ → 閉じて選択状態になる。「— 位置未登録」付き部位を選ぶ → panel に「この部位は現在の図では位置が未登録です。」

### T3. ズーム/パン
1. 「拡大」×3 → ズームされる。「縮小」→戻る。「全体に戻る」→ viewBox 初期化。
2. ドラッグでパン → 図が動く。ズーム+パン後にマーカータップ → 正しい部位が選択される。
3. ピンチ: adb では 2 本指不可 → 未検証と明記(sendevent 複雑すぎ)。

### T4. 詳細 overlay
1. 部位選択 →「詳しく読む」→ overlay(部位の解説)が開く。「閉じる」→ 解剖へ戻り選択維持。
2. Android back ボタン/ジェスチャーでも閉じること。
3. 「詳しく読む」5 連打 → overlay が 1 枚だけ・落ちない。
4. overlay 内 PartSheet の「保存」「覚えたにする」トグル動作。

### T5. 図鑑
1. 件数「52 部位」+「覚えた N / 52」表示。
2. 検索「かんぞう」→ 1件(肝臓)。「肝臓」漢字でも同様。存在しない語「ぬふぬふ」→ 0件+空表示。200 文字入力 → 落ちない。「消去」→ 52件復帰。
3. 絞り込み: 層(筋肉)・場所・向きを各 1 個 + 組み合わせ → 件数減少。「すべて解除」で全解除。
4. リスト最下部までスクロール → 崩れなし。
5. 行タップ → 詳細(和名/学名/はたらき/向き)。「解剖図で位置を見る」→ 解剖タブへ部位選択状態で遷移。
6. 詳細→「図鑑へ戻る」→ 検索語・絞り込み・スクロール位置が保持される。
7. 行の図アイコン(マップリンク)タップ → 解剖図へ飛ぶ。

### T6. 保存タブ + 永続化
1. 詳細で「保存」→ 保存タブに行が出る。count 増加。
2. 「保存解除」→ undo バー「○○ の保存を解除しました。」+「取り消す」→ 復元される。
3. `adb shell am force-stop host.exp.exponent` → relaunch → 保存/覚えた が残っている(AsyncStorage equus.saved.v1/equus.mastery.v1)。

### T7. 覚えた(mastery)
1. 複数部位で「覚えたにする」→ catalog の「覚えた N / 52」が増える。行に learned マーク。
2. もう一度押す → 解除。再起動後も残る。

### T8. モンキー/エッジ
1. 画面全体にランダム 100+ tap/swipe → クラッシュしない、真っ白にならない。
2. back 連打 → 壊れない。
3. ホームへ行き復帰 → 状態保持。
4. `settings put system user_rotation 1` → アプリは portrait のまま崩れない(orientation: portrait)。戻す。
5. 機内モード ON → 全機能オフラインで動作 → OFF に戻す。
6. `font_scale 1.3` → テキスト溢れ/クリップを目視 → 1.0 に戻す。
7. システム dark/light 切替 → app.json は dark 固定のはずだが崩れないか確認。

### T9. UI ポリッシュ観察 (常時)
- 肩まわり 5 ラベル重なりの現状、文字クリップ、コントラスト、タップ領域、日本語表記ゆれを目視記録。

### T10. ログ収集
- 最後に /tmp/logcat_err.log と `adb logcat -d` の ReactNativeJS:E/W、AndroidRuntime FATAL を収集。

## 想定ユーザストーリー

- 初見ユーザーが何も知らずタップしまくる(モンキー)。
