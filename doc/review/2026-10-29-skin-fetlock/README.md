## 手順どおりの実施内容

1. **計測**: 独立参照 `doc/reference-mask/left-skin-2026-10-29-devin.json` を作成。crop.ts のグリッド付き切り出し（3x/4x/6x の3段）で脚の輪郭を目視採取。最初の採取は候補の頂点列を見ずに行った（部位 id と検索範囲の bbox のみ使用）。ただし機械比較の重ね画像（現行 draft を含む）を見た後に形を直したため、参照ファイルの `blindToCandidates` は `false`（候補を見た参照）とする。`measure:independent` はこの参照の数値を出すが、合否には数えない。
2. **機械比較**: `pnpm measure:independent` で独立参照と候補座標を比較 → **不一致（IoU 0.537・境界95%点 20.0px）**。`skin-fetlock-compare.jpg`（緑=現行 draft、青=独立参照）で原因を特定。この数値は参照を最初に採った時の物。参照ファイルを採用候補の形へ直した後の現行の値は **IoU 0.552・境界95%点 18.4px**（2026-11-01 に `pnpm measure:independent` で再実行。`blindToCandidates: false` に直した後は `not-independent` と出て、数値は出るが合否に数えない）。
3. **採用候補**: 独立参照側を推奨。現行 draft は脚の斜行に沿った帯で、関節の上前部（x568-580・y1008-1012）と後下部（x596-622・y1040-1060）が範囲外に抜けていた。独立参照は脚の前縁（y1010 で x560 → y1060 で x540 の斜行）と後縁（x620-630）の実輪郭に沿う。**最終採否は人の相互確認待ち。**

## 判断根拠

- 原画像: `assets/anatomy/skin_left.jpg`（1600×1200）。球節は管骨と繋骨の間の関節隆起で、左側望では脚の前縁が斜行する区間に位置する。
- 解剖学的定義: 球節（fetlock joint）= 第三中手骨（前肢の管骨）と基節骨の関節部（この部位は左前肢。座標 x560-630 は前肢の位置）。側面では掌側（後方）に種子骨の隆起が出る。採用ポリゴンはこの隆起を含む関節域全体を覆う。
- 数値の扱い: measure:independent の不一致（0.537）は draft の範囲不足が主因。一度 measured へ上げた時（差し戻し済み）は、採用候補の座標を参照ファイルと同じ形にしたため IoU 1.0・境界95%点 0px になった。**これは同じ計測者が作った形どうしの一致で、人同士の相互確認ではない**。measured 昇格の判定材料としては使わない。今の draft 座標との比較は IoU 0.552 で、数値の上では大きくずれる。ただしこの参照は候補を見た後に直したので、合否には数えない（手順 2）。
