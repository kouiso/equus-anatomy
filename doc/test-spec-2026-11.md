## 3つの目

- **仕様の目（S）**: README・AGENTS.md・issue の完了条件に書いてある動きが、その通りに出るか
- **意地悪な試験者の目（T）**: 壊れた入力・直接の URL・連打・保存データの破損・小さな画面と文字拡大で、落ちたり行き止まりになったりしないか
- **利用者の話の目（U）**: 学ぶ人が実際にやりそうな一続きの操作が、途中で迷わず最後まで行けるか

|---|---|---|---|

| T03 | 意地悪 | 保存と学習記録の保存データを壊してから開く | 一覧が出て、ページのエラーが出ない |
| T04 | 意地悪 | 検索に絵文字・200 文字・空白だけを入れる | 落ちず、0 件の案内か全件に戻る |
| T05 | 意地悪 | 絞り込みのボタンを素早く2回押す | 選択肢の画面は1つだけ開き、閉じれば元に戻る |
| T06 | 意地悪 | 選択肢の画面で何も選ばずに Escape | 何も変わらずに閉じる |
| T07 | 意地悪 | 320×568・文字200% の図鑑 | 絞り込みのボタンと「図」が画面からはみ出さず、名前が省略されない |
| T08 | 意地悪 | `/?part=bogus` を開く | 落ちず、解剖画面が出る |
| T09 | 意地悪 | 図鑑を 390px で開いてから 1440px へ広げる | 行が2段から1行の横並びに替わる |
| T10 | 意地悪 | 存在しない URL `/no-such-page` | アプリへ戻る導線のある 404 が出る |
| U01 | 利用者 | 筋肉のうち、まだ覚えていない部位を1つ覚える | 図鑑 → 層「筋肉」→「まだ」→ 部位を開く →「覚えたにする」→ 戻る、で件数が1つ減り、その部位が外れている |
| U02 | 利用者 | 「くび」の部位をローマ字で探して図で見る | 「kubi」で検索 → 頸の行の「図」→ 解剖図で頸が選ばれている |

| U04 | 利用者 | 英語で図鑑を眺める | 英語に切り替え → 図鑑 → 行の名前が英語 |
| U05 | 利用者 | 2つ保存して、次の日（再読み込み）に保存から開く | 再読み込みの後も保存の一覧に2つ残り、行から詳細を開ける |
